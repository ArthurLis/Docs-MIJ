# Estrutura GitBook

Esta pasta foi preparada como esqueleto de documentação. O conteúdo está propositalmente resumido para permitir expansão manual.

Arquivos principais:

- `.gitbook.yaml`: configuração do GitBook.
- `README.md`: página inicial.
- `SUMMARY.md`: navegação.
- `docs/`: páginas.
- `assets/`: imagens e arquivos de apoio.

Os comentários HTML `<!-- ... -->` servem como lembretes de edição e não aparecem na página renderizada.
