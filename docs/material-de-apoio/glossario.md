# Glossário

| Termo | Descrição |
| --- | --- |
| ADR | Adaptive Data Rate. Mecanismo do LoRaWAN que ajusta automaticamente parâmetros como Data Rate e potência de transmissão para melhorar alcance, consumo e tempo no ar. |
| ABP | Activation By Personalization. Método de ativação LoRaWAN em que o dispositivo já possui previamente o endereço e as chaves de sessão necessárias para se comunicar com a rede. |
| OTAA | Over-The-Air Activation. Método de ativação LoRaWAN em que o dispositivo realiza um processo de Join com a rede para obter uma nova sessão e suas respectivas chaves. |
| RSSI | Received Signal Strength Indicator. Indica a potência do sinal recebido, normalmente expressa em dBm. |
| SNR | Signal-to-Noise Ratio. Relação entre a intensidade do sinal recebido e o nível de ruído, expressa em dB. |
| SF | Spreading Factor. Parâmetro LoRa que influencia alcance, robustez e tempo de transmissão. Valores maiores aumentam a sensibilidade, mas também aumentam o tempo no ar. |
| DR | Data Rate. Índice utilizado pelo LoRaWAN para representar uma combinação de parâmetros de transmissão, como Spreading Factor e largura de banda. |
| Sync Word | Valor utilizado pelo rádio para diferenciar redes ou grupos de dispositivos LoRa que utilizam os mesmos parâmetros de modulação. |
