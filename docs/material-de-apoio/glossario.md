# Glossário

| Termo | Descrição |
| --- | --- |
| ADR | **Adaptive Data Rate.** Mecanismo do LoRaWAN que ajusta parâmetros de comunicação para melhorar eficiência, alcance e tempo no ar. |
| ABP | **Activation By Personalization.** Ativação em que o dispositivo já possui os parâmetros de sessão necessários para se comunicar com a rede. |
| OTAA | **Over-The-Air Activation.** Ativação em que o dispositivo realiza um Join com a rede antes de utilizar a sessão LoRaWAN. |
| RX1 | Primeira janela de recepção aberta por um dispositivo Class A após um uplink. |
| RX2 | Segunda janela de recepção aberta após RX1 caso não exista uma recepção válida na primeira janela. |
| RSSI | **Received Signal Strength Indicator.** Indica a potência do sinal recebido, normalmente em dBm. |
| SNR | **Signal-to-Noise Ratio.** Relação entre o sinal recebido e o ruído, normalmente em dB. |
| SF | **Spreading Factor.** Parâmetro LoRa que influencia alcance, robustez, taxa de dados e tempo no ar. |
| DR | **Data Rate.** Índice LoRaWAN que representa uma configuração de taxa de dados da região utilizada. |
| Sync Word | Valor utilizado pelo rádio para diferenciar transmissões LoRa com parâmetros de modulação semelhantes. |
